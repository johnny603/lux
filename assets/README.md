# Asset Directory Structure

This directory holds visual assets, themes, and design concepts for the **Lux** puzzle and escape room platform.

## Subdirectories

- **`/backgrounds/`**: Room-specific atmospheric background illustrations (WebP/PNG format, max 200KB per asset). Recommended resolution: `1920x1080` (or `16:9` ratio).
- **`/icons/`**: Object sprites, inventory items, navigation pointers, and UI interactive indicators (SVG format preferred).
- **`/themes/`**: Room-specific CSS variable palettes (`theme_<room_id>.css`) overriding base theme design tokens.
- **`/concepts/`**: Mood boards, wireframes, color stories, and sketches for upcoming rooms.

For contribution workflow, specifications, and naming conventions, please refer to [`CONTRIBUTING_DESIGN.md`](../CONTRIBUTING_DESIGN.md).
